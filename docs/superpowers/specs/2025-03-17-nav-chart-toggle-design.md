# 基金历史净值走势卡片 - 单位净值切换功能设计文档

## 背景与目标

### 问题
当前基金详情页的历史净值走势卡片仅显示涨跌幅百分比（归一化后的相对变化），用户无法直接查看基金单位净值的绝对值走势。

### 目标
在保持现有涨跌幅视图的基础上，增加单位净值走势视图，让用户可以切换查看两种数据展示方式。

## 设计方案

### UI 设计

在 Card 组件的标题区域（extra 属性）增加视图切换按钮，与现有的时间段选择器并排或分层展示：

```
┌─────────────────────────────────────────────┐
│ 历史净值走势           [单位净值|涨跌幅] [近3月▼] │
├─────────────────────────────────────────────┤
│                                             │
│              ╭────────────────╮             │
│    1.5000    │                │             │
│    1.2500    │   ╱╲           │             │
│    1.0000    │  ╱  ╲___       │             │
│              │         ╲      │             │
│              ╰────────────────╯             │
│                   时间轴                     │
│                                             │
└─────────────────────────────────────────────┘
```

### 功能规格

| 属性 | 涨跌幅模式 | 单位净值模式 |
|------|-----------|-------------|
| 视图标识 | `change` | `nav` |
| Y轴单位 | % | 元 |
| 数据系列 | 3条线（本基金/业绩基准/沪深300） | 1条线（本基金单位净值） |
| 数据计算 | 归一化百分比变化 | 原始单位净值 |
| 基准说明 | 以时间段起点为基准(100%) | 无 |

### 组件变更

**文件**: `frontend/src/components/NavHistoryChart.tsx`

#### 1. 新增状态
```typescript
const [viewMode, setViewMode] = useState<'change' | 'nav'>('change');
```

#### 2. 新增视图选项配置
```typescript
const VIEW_MODE_OPTIONS = [
  { label: '涨跌幅', value: 'change' },
  { label: '单位净值', value: 'nav' },
];
```

#### 3. UI 布局调整
- 使用 `Segmented` 组件或 `Radio.Group` 实现切换按钮
- 放置在 Card extra 区域，与时间段选择器形成视觉层次

#### 4. 图表渲染逻辑调整
根据 `viewMode` 状态渲染不同的图表配置：

**涨跌幅模式 (`change`)**：
- 保持现有实现不变
- Y轴名称：涨跌幅(%)
- 3条数据线（本基金/业绩基准/沪深300）

**单位净值模式 (`nav`)**：
- 单条线显示本基金单位净值
- Y轴名称：单位净值(元)
- Tooltip 显示格式：`日期<br/>单位净值: 1.2345元`
- 无需归一化处理，直接使用 `nav` 字段

### 数据格式

已有数据格式支持（无需后端变更）：
```typescript
interface NavHistoryPoint {
  date: string;
  nav: number;        // 单位净值 - 用于 nav 模式
  nav_acc?: number;   // 累计净值
}
```

## 实现细节

### 图表配置差异

| 配置项 | 涨跌幅模式 | 单位净值模式 |
|--------|-----------|-------------|
| series | 3条line | 1条line |
| yAxis.name | '涨跌幅(%)' | '单位净值(元)' |
| yAxis.axisLabel.formatter | '{value}%' | '{value}' |
| tooltip.formatter | 显示百分比，带+/-符号和颜色 | 显示净值，保留4位小数 |
| legend.data | ['本基金', '业绩基准', '沪深300'] | ['单位净值'] |
| colors | 蓝/黄/绿 | 蓝色 |

### 状态持久化

当前实现不涉及URL参数或本地存储持久化，切换仅影响当前组件状态。

## 测试要点

1. **功能测试**：
   - 点击切换按钮能正确切换视图
   - 涨跌幅模式显示3条线，单位净值模式显示1条线
   - 切换时间段后保持当前视图模式

2. **数据正确性**：
   - 单位净值模式显示原始 `nav` 值，不归一化
   - Tooltip 显示正确的单位和精度

3. **边界情况**：
   - 数据为空时的处理
   - 切换模式时图表正确销毁和重建
